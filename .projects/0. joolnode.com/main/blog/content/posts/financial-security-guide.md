# 소중한 내 자산을 지키는 3가지 필수 보안 수칙

보이스피싱과 스미싱이 날로 교묘해지고 있습니다. 시니어분들이 꼭 알아야 할 스마트폰 보안 설정법을 안내합니다.

## 1. 모르는 번호의 문자는 의심부터
문자 메시지에 포함된 인터넷 주소(URL)는 절대 클릭하지 마세요. 공식 기관은 문자로 개인정보나 돈을 요구하지 않습니다.

## 2. 스마트폰 보안 설정 강화
안드로이드 폰의 경우 '출처를 알 수 없는 앱 설치 제한' 기능을 항상 켜두어야 합니다.

## 3. 원격 제어 앱 주의
누군가 '문제 해결을 위해 앱을 깔아달라'고 한다면 100% 사기입니다. 원격 제어 앱은 절대 설치하지 마세요.

> 이상한 낌새가 느껴질 때는 즉시 자녀나 경찰(112)에 도움을 요청하세요.
